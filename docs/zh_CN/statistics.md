# 1.8.8 战绩与指南针

## 已有统计

1.8.8 与 1.21.11 使用相同的主要战绩字段和持久化语义。

| 数据 | 生涯统计 | 逐局统计 |
| --- | --- | --- |
| 普通击杀、最终击杀、总击杀 | 分别保存，合计由前两者相加 | 普通与最终分别保存，可计算合计 |
| 死亡 | 普通死亡、最终死亡分别保存 | 合并为死亡数 |
| 挖床数 | 保存 | 保存 |
| 胜负、场次数 | 累计胜场、败场、参与场次 | 每位玩家结局、对局状态与编号 |
| 首次/最后游玩时间 | 保存 | 保存对局开始与结束时间 |
| 重连、掉线、违规证据 | 不属于生涯基础计数 | 在对局明细和事件中保存 |

生涯统计写入 MySQL 或 SQLite 的 `global_stats`，与 `match-statistics.enabled` 控制的对局历史相互独立。
对局历史启用后使用共享 MySQL，未启用 MySQL 时使用本地 `Cache/matches.db`；配置 MySQL 但连接失败时不会静默换本地库。

- `/bw stats`：生涯统计界面。
- `/bw match <编号或UUID>`：单局及参赛玩家战绩。
- `/bw history <玩家>`：个人对局历史。
- `/bw record <玩家>`：已完成对局的累计战绩。

PlaceholderAPI 可用时，排行榜可读取：

| 数据 | 占位符 |
| --- | --- |
| 挖床数 | `%bw1058_stats_bedsdestroyed%` |
| 最终击杀 | `%bw1058_stats_finalkills%` |
| 普通击杀 | `%bw1058_stats_kills%` |
| 总击杀 | `%bw1058_stats_total_kills%` |
| 普通死亡 | `%bw1058_stats_deaths%` |
| 最终死亡 | `%bw1058_stats_finaldeaths%` |
| 胜场 / 败场 | `%bw1058_stats_wins%` / `%bw1058_stats_losses%` |
| 场次数 | `%bw1058_stats_gamesplayed%` |
| K/D | `%bw1058_stats_kd%` |

逐局和对局累计 K/D 使用普通击杀除以全部死亡，零死亡时分母为 1；最终击杀不计入分子。
生涯排行榜 K/D 同样使用普通击杀及全部死亡，并且只向生涯场次严格超过 100 场的玩家返回数字。

## 指南针

开局和复活时发放在快捷栏第 9 格。自动指向最近有效敌人，每 2 tick 更新一次；不需右键选择。
底部每秒显示与指针相同的目标名称和距离，单人队同样生效。排除队友、隐身敌人、旁观者、死亡、复活等待、离线、已离场及其他世界玩家。
无有效敌人时指针旋转，不显示新的追踪提示。死亡和掉线掉落物会过滤追踪指南针。
中文默认提示从队伍名升级为玩家名；管理员自定义文本继续保留，仍支持 `{player}`、`{team}` 和 `{distance}`。
