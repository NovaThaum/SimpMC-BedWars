# BedWars 配置迁移工具

此独立工具把 1.21.11 的 YAML 配置值合并进 1.8.8 插件生成的目标配置模板。它不启动服务器，不修改输入文件，也不会将 1.21.11 的 `config-version` 带入旧版配置。

需要 Java 21 或更新版本。先运行一次 1.8.8 服务器生成配置，然后停服并执行：

```text
java -jar bedwars-config-migrator-1.0.0.jar <1.21插件数据目录> <1.8插件数据目录>
```

工具自动递归查找两个目录中的 YAML。`Cache/` 会主动跳过，由 1.8.8 插件重新获取地图缓存。普通配置只合并两个目录里相对路径相同的文件；`Arenas/` 下目标版尚不存在的新地图会从现代文件生成旧版文件，并移除现代架构版本字段、旧版不读取的 `minInTeam`，补齐旧版游戏规则。语言文件会迁移同路径的管理员文本，并补入目标文件缺少的新版标量键；结构类型冲突会保留目标值并记录。迁移结果直接写入 1.8 插件数据目录中对应的配置文件，并在该目录生成 `migration-report.txt`。普通配置以现有 1.8 模板为目标结构；旧版不支持或结构不兼容的路径会列在报告中。对材料名和声音名执行的已知映射也会记录在报告里。

工具会直接覆盖目标目录里存在对应模板的配置文件，也会直接创建新竞技场文件。先停止 1.8.8 服务器并备份两个插件目录，再传入插件数据目录本身，而不是 `plugins/` 父目录。检查 `migration-report.txt` 中的未迁移项和映射结果后，启动服务器加载配置。该工具不会自动转换竞技场坐标、物品附魔/自定义数据、代理设置或数据库内容。
