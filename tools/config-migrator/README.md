# BedWars 配置迁移工具

此独立工具把 1.21.11 的 YAML 配置值合并进 1.8.8 插件生成的目标配置模板。它不启动服务器，不修改输入文件，也不会将 1.21.11 的 `config-version` 带入旧版配置。

需要 Java 21 或更新版本。先运行一次 1.8.8 服务器生成配置，然后停服并执行：

```text
java -jar bedwars-config-migrator-1.0.0.jar <1.21插件数据目录> <1.8插件数据目录>
```

工具自动递归查找两个目录中相对路径相同的 YAML。结果写在 1.8 插件目录的 `migration-output/`，目录结构与原配置相同，并生成 `migration-report.txt`。只有目标模板中已经存在的路径会被迁移；1.8 模板的结构和默认键作为目标结构。无法对应的现代版配置路径会列在报告中，不会被写入目标文件。对材料名和声音名执行的已知映射也会记录在报告里。

先停服并备份两个插件目录。传入插件数据目录本身，而不是 `plugins/` 父目录。确认报告和输出无误后，再把 `migration-output/` 中的文件合并回 1.8.8 插件目录。该工具不会自动转换竞技场坐标、物品附魔/自定义数据、代理设置或数据库内容。
